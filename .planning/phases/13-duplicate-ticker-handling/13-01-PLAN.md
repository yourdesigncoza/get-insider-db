   - reset_index(drop=True)

   - Return empty DataFrame unchanged (guard clause)
   - Work on df.copy() to avoid mutation
   - Add `duplicate_count` column: number of times each ticker appears (via value_counts map)
   - Add `duplicate_rank` column: rank by cluster_score within ticker group (1 = highest, method='min')
   - Cast duplicate_rank to int
   - Return annotated copy

In `scripts/scan_clusters.py`, make these changes:

b) Add CLI argument after the existing `--print` argument:
   ```python

       "--deduplicate",
   ```

c) After the `get_top_cluster_buys()` call and the empty check, but BEFORE the `if args.print_table:` block, insert deduplication logic. The key ordering is:
   - Query returns full results (existing)
   - Apply deduplication OR annotation (new)
   - Then limit truncation (move --limit enforcement here if dedup active)
   - Then print/export (existing)

   Specifically:
   ```python
   # Track pre-processing counts
   total_clusters = len(df)
   unique_tickers = df['ticker'].nunique()

   if args.deduplicate:
       df = deduplicate_by_highest_score(df)
       removed = total_clusters - len(df)
       if removed > 0:
           print(f"Deduplicated: {removed} duplicate clusters removed "
                 f"({len(df)} unique tickers from {total_clusters} total)")
   else:
       # Annotate duplicates for console display awareness
       df = annotate_duplicates(df)
       dup_tickers = len(df[df['duplicate_count'] > 1]['ticker'].unique()) if 'duplicate_count' in df.columns else 0
       if dup_tickers > 0:
           print(f"Note: {dup_tickers} tickers appear multiple times "
                 f"(use --deduplicate to keep only highest-scoring per ticker)")
   ```

d) For dedup-before-limit: When --deduplicate is active, pass a larger limit (or no limit) to get_top_cluster_buys, then truncate after dedup. Implementation approach:
   - If --deduplicate is set, call get_top_cluster_buys with `limit=0` (which means no limit in the existing API, check the function signature) or a sufficiently large number, then deduplicate, then truncate to args.limit.
   - If limit=0 is not supported, use limit=args.limit * 5 as a heuristic buffer (research shows ~40% duplication rate, so 5x gives safe margin).
   - After dedup, apply: `df = df.head(args.limit)` to enforce the user's requested limit.

e) In `format_rows()`, add duplicate annotation columns to console display ONLY (not JSON). After the existing `has_avg_sale_to_purchase_ratio` check, add:

   Then in the Rich table columns list, after the "Ticker" column, conditionally add:
   ```python
   if has_duplicate_count:
       columns.insert(1, ("duplicate_rank", "#", "right"))  # compact header
   ```
   And similarly for the tabulate and plain-text fallbacks.

f) For JSON export: Strip duplicate_count and duplicate_rank columns from `out_df` before writing, since these are console-only annotations:
   ```python
   out_df = df.copy()
   # Remove console-only annotation columns from JSON export
   for col in ("duplicate_count", "duplicate_rank"):
       if col in out_df.columns:
           out_df = out_df.drop(columns=[col])
   ```

g) Add `deduplicated` boolean and `unique_tickers` count to the metadata dict so JSON consumers know if dedup was applied:
