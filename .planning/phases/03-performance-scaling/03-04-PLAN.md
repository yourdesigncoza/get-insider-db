**Implementation:**
1. Determine output path: `{stem}_enriched{suffix}`
2. If use_streaming:

   - Read metadata separately via read_metadata()
   - Process batches via process_batches()
   - Write incrementally via write_clusters_streaming()
3. Else (small files):
   - Load entire JSON (for files <100 clusters)
   - Enrich via enricher.enrich_batch()
   - Write entire JSON

- Use asyncio.Queue or simple counter for progress
- Final summary: clusters processed, errors, time elapsed
