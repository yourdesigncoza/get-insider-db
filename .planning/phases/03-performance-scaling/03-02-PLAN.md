3. Create `src/services/streaming.py`:

   **Class ClusterStreamReader:**
   - `__init__(file_path: Path | str)`
   - `def __iter__() -> Iterator[dict]` - yields clusters one at a time
   - Uses `ijson.items(f, 'rows.item')` to stream from `{"rows": [...], "metadata": {...}}` structure
   - Handles both file paths and file-like objects

   **Function stream_clusters(file_path: Path | str) -> Iterator[dict]:**
   - Convenience wrapper around ClusterStreamReader
   - Opens file in binary mode ('rb') as required by ijson
   - Yields each cluster dict from the 'rows' array

   **Function read_metadata(file_path: Path | str) -> dict:**
   - Extract just the metadata object without loading rows
   - Uses ijson.items with 'metadata' prefix
   - Returns empty dict if no metadata found

   **Function write_clusters_streaming(clusters: Iterator[dict], output_path: Path, metadata: dict = None):**
   - Write clusters to JSON one at a time
   - Opens file, writes opening `{"rows": [`
   - Iterates clusters, writing each with json.dumps + comma handling
   - Closes with `], "metadata": {...}}`
   - Memory-efficient: doesn't accumulate all results before writing

Example usage:
```python
# Reading
for cluster in stream_clusters("large_export.json"):
    enriched = await enrich(cluster)
    yield enriched

# Writing
write_clusters_streaming(enriched_clusters, output_path, metadata={"enriched_at": "..."})
```

Use ijson (not json.load) for reading large files.
Use incremental writing (not json.dumps on full list) for output.

Extend `src/services/streaming.py` with batch utilities:

**Function batch_clusters(clusters: Iterator[dict], batch_size: int = 50) -> Iterator[list[dict]]:**
- Groups clusters into batches for efficient async processing
- Yields lists of up to batch_size clusters
- Final batch may be smaller

**Async Generator process_batches(clusters: Iterator[dict], processor: Callable, batch_size: int = 50) -> AsyncIterator[dict]:**
- Batches clusters using batch_clusters()
- Calls `await processor(batch)` for each batch
- Yields individual results from each batch
- Enables: concurrent processing within batches, sequential between batches

Example:
```python
async def enrich_batch(batch: list[dict]) -> list[dict]:
    return await asyncio.gather(*[enrich(c) for c in batch])

async for enriched in process_batches(stream_clusters(path), enrich_batch, batch_size=50):
    yield enriched
```

batch_size=50 is the default based on research recommendations (balance memory vs overhead).
