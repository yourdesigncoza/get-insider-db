<objective>
Re-key market_prices, market_fundamentals, and cluster_events tables from ticker-based to CIK-based identifiers.

Purpose: Eliminates data fragmentation when tickers change (FB->META). CIK is permanent, ticker is now metadata.
Output: Three migration SQL scripts + updated schema.sql DDL reflecting CIK-based primary keys.
</objective>

  <action>
Create three idempotent migration scripts:

**sql/migrate_market_prices_to_cik.sql:**
1. Drop old primary key constraint `market_prices_pkey`
2. Drop redundant index `idx_market_prices_ticker_date`
3. Add `issuer_cik TEXT` column
4. TRUNCATE table (fresh start per user decision - data is re-fetchable)
5. Make `issuer_cik` NOT NULL
6. Make `ticker` nullable (DROP NOT NULL)
7. Create new primary key: `PRIMARY KEY (issuer_cik, price_date)` -- CIK first for query efficiency
8. Create index on ticker for reverse lookups: `CREATE INDEX idx_market_prices_ticker ON market_prices(ticker)`

**sql/migrate_market_fundamentals_to_cik.sql:**
Same pattern as market_prices:
1. Drop old primary key constraint `market_fundamentals_pkey`
2. Drop redundant index `idx_market_fundamentals_ticker_date`
3. Add `issuer_cik TEXT` column
4. TRUNCATE table (fresh start)
5. Make `issuer_cik` NOT NULL
6. Make `ticker` nullable (DROP NOT NULL)
7. Create new primary key: `PRIMARY KEY (issuer_cik, date)` -- CIK first
8. Create index on ticker: `CREATE INDEX idx_market_fundamentals_ticker ON market_fundamentals(ticker)`

**sql/migrate_cluster_events_to_cik.sql:**
NOTE: cluster_events keeps `cluster_id` as PK (auto-increment). We ADD issuer_cik, not change PK.
1. Add `issuer_cik TEXT` column (nullable initially)
2. Populate from mapping table: `UPDATE cluster_events ce SET issuer_cik = m.issuer_cik FROM issuer_cik_ticker_map m WHERE ce.ticker = m.ticker`
3. STRICT EXCLUSION: `DELETE FROM cluster_events WHERE issuer_cik IS NULL` (cascade will clean cluster_event_members + signal_history via ON DELETE CASCADE)
4. Make `issuer_cik` NOT NULL
5. Add foreign key: `FOREIGN KEY (issuer_cik) REFERENCES issuer_cik_ticker_map(issuer_cik)`
6. Create index: `CREATE INDEX idx_cluster_events_issuer_cik ON cluster_events(issuer_cik)`
7. Make `ticker` nullable: `ALTER COLUMN ticker DROP NOT NULL`

Each script should be wrapped in a transaction (BEGIN/COMMIT) for atomicity.

After writing scripts, apply them to the database via psql:
```bash

psql $DATABASE_URL -f sql/migrate_market_fundamentals_to_cik.sql
psql $DATABASE_URL -f sql/migrate_cluster_events_to_cik.sql
```
