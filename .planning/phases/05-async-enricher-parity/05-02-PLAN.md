  <files>scripts/enrich_clusters_async.py</files>
  <action>
Modify enrich_clusters_async.py to add checkpointing in memory mode:

1. Add imports at top:
   ```python
   from src.checkpointing.checkpoint_manager import CheckpointManager
   from src.config import get_engine
   ```

2. Add CHECKPOINT_FREQUENCY constant: `CHECKPOINT_FREQUENCY = 25`

3. Modify `enrich_small_file()` function signature:
   - Add `resume: bool = True` parameter
   - Add `checkpoint_mgr: CheckpointManager | None = None` parameter

4. Inside `enrich_small_file()`:
   a. Generate run_id: `run_id = f"async_enrich_{file_path.stem}"`
   b. If resume and checkpoint_mgr:
      - Check for existing checkpoint: `checkpoint = checkpoint_mgr.get_checkpoint(run_id)`
      - If checkpoint exists, set `start_index = checkpoint["last_index"] + 1`
      - Log: `logger.info("resuming_from_checkpoint", start_index=start_index)`
   c. Initialize tracking: `processed_tickers: list[str] = []`, `errors: dict[str, str] = {}`
   d. Slice clusters: `enriched_rows = clusters[:start_index]` (keep already processed)
   e. Adjust loop: `for i, cluster in enumerate(clusters[start_index:], start_index):`
   f. After enriching each cluster:
      - Track: `processed_tickers.append(cluster.get("ticker", f"row_{i}"))`
      - If error, track in errors dict
   g. Checkpoint periodically (inside loop):
      ```python
      if checkpoint_mgr and (i + 1) % CHECKPOINT_FREQUENCY == 0:
          checkpoint_mgr.save_checkpoint(
              run_id=run_id,
              last_index=i,
              processed_tickers=processed_tickers,
              errors=errors,
          )
          logger.info("checkpoint_saved", index=i + 1, total=total)
      ```
   h. After loop completes successfully:
      - Clear checkpoint: `if checkpoint_mgr: checkpoint_mgr.clear_checkpoint(run_id)`

5. Modify `process_file()`:
   - Add `resume: bool = True` parameter
   - Initialize CheckpointManager: `engine = get_engine(); checkpoint_mgr = CheckpointManager(engine)`
   - Pass to enrich_small_file: `checkpoint_mgr=checkpoint_mgr, resume=resume`

6. Modify `main()`:
   - Add argparse argument: `--no-resume` (action="store_true")
   - Pass `resume=not args.no_resume` to process_file()

Note: Streaming mode does NOT get checkpointing (per research pitfall #5). Only memory mode (<50 clusters or --no-streaming) supports resume.
