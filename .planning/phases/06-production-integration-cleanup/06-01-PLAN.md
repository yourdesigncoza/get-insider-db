<task type="auto">
  <name>Task 2: Wire SignalHistoryRecorder into async enrichment</name>
  <files>scripts/enrich_clusters_async.py</files>
  <action>
Import SignalHistoryRecorder from src.audit and wire it into both enrich_small_file() and enrich_streaming().

1. Import at top: `from src.audit import SignalHistoryRecorder`

2. In enrich_small_file():
   - Create recorder instance after engine: `recorder = SignalHistoryRecorder(engine)`
   - After successful enrichment of each cluster (in the try block after enriched_rows.append):
     - Check if cluster has cluster_id (from DB join in export)
     - If cluster_id exists, record event with try/except to avoid crashing on recording failure:
     ```python
     if enriched.get("cluster_id"):
         try:
             recorder.record_event(
                 cluster_id=enriched["cluster_id"],
                 event_type="enriched",
                 changed_by="async_enrichment",
                 new_values={
                     "enrichment_status": enriched.get("enrichment_status"),
                     "price_at_entry": enriched.get("price_at_entry"),
                     "adjusted_cluster_score": enriched.get("adjusted_cluster_score"),
                 },
                 reason=f"Async enriched: {enriched.get('enrichment_status', 'unknown')}"
             )
         except Exception as e:
             logger.warning("signal_history_record_failed", cluster_id=enriched["cluster_id"], error=str(e))
     ```

3. In enrich_streaming():
   - Same pattern: create recorder, record after each cluster is enriched
   - Use get_engine() to get sync engine for recorder (SignalHistoryRecorder uses sync engine)

Note: SignalHistoryRecorder uses sync SQLAlchemy engine, not async. This is intentional — the recorder is lightweight and the sync call won't block meaningfully. Creating an async version is out of scope for this cleanup phase.
  </action>
