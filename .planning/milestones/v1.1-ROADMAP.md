# Milestone v1.1: Result Quality 01

**Status:** SHIPPED 2026-02-11
**Phases:** 8-14
**Total Plans:** 7

## Overview

Improved cluster scan output quality by filtering false positives, excluding non-tradeable entities, debugging broken features, and cleaning export formatting.

## Phases

### Phase 8: Fund Ratio Filtering
**Goal**: Exclude fund-heavy clusters from scan results
**Depends on**: Phase 7 (value filter config infrastructure)
**Plans**: 1 plan

Plans:
- [x] 08-01: Fix boundary operators, add fund_ratio to output, wire CLI defaults, add boundary tests

**Details:**
Strict exclusive boundary filtering (`< max_fund_ratio`). Zero-denom guard for clusters with 0 total insiders. Config-driven CLI defaults for --max-fund-ratio. 9 boundary tests added.

### Phase 9: N/A Ticker Exclusion
**Goal**: Prevent non-tradeable tickers from appearing in results
**Depends on**: Phase 8
**Plans**: 1 plan

Plans:
- [x] 09-01: Add N/A/empty ticker exclusion to SQL queries, metadata documentation, and tests

**Details:**
SQL-level filtering of invalid ticker literals (N/A, NONE, empty) in all 3 query locations. Exclusion count logging. 18 unit tests added.

### Phase 10: Window Span Validation
**Goal**: Investigate and correct window merging behavior that creates spans exceeding window_days
**Depends on**: Phase 9
**Plans**: 1 plan

Plans:
- [x] 10-01: Fix window merge span validation and add regression tests

**Details:**
Fixed DATA-01 where 9/20 clusters had spans up to 37 days (limit: 10). Added span check before merging. Overlapping windows exceeding constraint kept as separate events. 11 regression tests.

### Phase 11: Issuer CIK Population
**Goal**: Populate issuer_cik field in scan output
**Depends on**: Phase 10
**Plans**: 1 plan

Plans:
- [x] 11-01: Add issuer_cik to insider_buy_signals view, apply migration, add regression tests

**Details:**
SQL view schema extension with zero Python changes. Existing `_get_optional_column` auto-discovered new column. 9 tests added. CIK values verified as 10-digit zero-padded strings.

### Phase 12: Sale-to-Purchase Ratio Debug
**Goal**: Fix avg_sale_to_purchase_ratio always being 0.0
**Depends on**: Phase 11
**Plans**: 1 plan

Plans:
- [x] 12-01: Create insider_trade_signals view, wire P+S data into ratio calculation, add tests

**Details:**
Root cause: insider_buy_signals only included purchases. Created separate insider_trade_signals view (P+S). Batch-loaded sales data. Graceful fallback if view missing. 8 tests added.

### Phase 13: Duplicate Ticker Handling
**Goal**: Implement explicit strategy for same ticker appearing multiple times
**Depends on**: Phase 12
**Plans**: 1 plan

Plans:
- [x] 13-01: Add --deduplicate CLI flag, duplicate annotation in console, dedup utility with tests

**Details:**
Pure-function utilities for dedup and annotation. --deduplicate flag keeps highest-scoring per ticker. 5x query buffer for dedup mode. Console notifications for duplicate awareness. 10 tests added.

### Phase 14: Float Rounding
**Goal**: Round numeric export fields to 2 decimal places
**Depends on**: Phase 13
**Plans**: 1 plan

Plans:
- [x] 14-01: Extend rounding to all 5 float fields, add unit tests

**Details:**
FLOAT_FIELDS_TO_ROUND constant covers cluster_score, avg_percent_change, avg_days_to_file, fund_ratio, avg_sale_to_purchase_ratio. Copy-then-round pattern preserves internal precision. 5 tests added.

## Milestone Summary

**Key Decisions:**
- Strict exclusive fund_ratio boundary (clusters >= max excluded)
- Zero-denom guard for invalid clusters
- Overlapping windows kept separate (deferred dedup to Phase 13)
- Separate insider_trade_signals view (don't break buy signals)
- Deduplication as display concern (not detection logic)
- Pure functions for dedup utilities (testable, composable)
- Copy-then-round pattern for float precision

**Issues Resolved:**
- Fund-heavy clusters polluting results (FILT-01)
- Invalid tickers (N/A, NULL) in output (FILT-02)
- Window spans exceeding window_days config (DATA-01)
- Missing issuer_cik in scan output (DATA-02)
- avg_sale_to_purchase_ratio always 0.0 (DATA-03)
- Duplicate tickers confusing users (OUT-01)
- Noisy float precision in JSON exports (OUT-02)

**Issues Deferred:**
- pytest-asyncio not in requirements.txt (32 async tests skipped)
- Repository pattern (deferred since v1.0)

**Technical Debt Incurred:**
- None new — all 7 requirements shipped cleanly
