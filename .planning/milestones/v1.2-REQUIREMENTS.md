## v1.2 Requirements

Requirements for CIK-Based Enrichment milestone. Each maps to roadmap phases.

### Data Mapping

- [x] **MAP-01**: CIK-to-ticker mapping table populated from form345_submission data, using most recent filing's ticker when one CIK has multiple tickers
  - *Outcome: 8,982 mappings populated, ON CONFLICT upsert with date comparison, 98.8% zero-padding preserved*

### Schema Migration

- [x] **SCHEMA-01**: market_prices table re-keyed from (ticker, date) to (issuer_cik, date) with ticker retained as metadata column
  - *Outcome: market_prices, market_fundamentals, and cluster_events all re-keyed to CIK-based PKs. 25 unmapped cluster_events deleted (6%).*

### Enrichment Pipeline

- [x] **ENRICH-01**: Both enrich scripts (sync + async) use issuer_cik as primary lookup key, resolving ticker via mapping table for external API calls
  - *Outcome: All DB cache queries use WHERE issuer_cik, 0 ticker-based WHERE clauses remaining*
- [x] **ENRICH-02**: Clusters with missing issuer_cik or unmapped CIK excluded from enrichment output entirely
  - *Outcome: Sync returns None, async skips with continue. Pre-validation at CLI entry point.*
- [x] **ENRICH-03**: CIK resolution statistics printed as summary at end of enrichment run (resolved count, missing CIK count, unmapped count)
  - *Outcome: Both scripts log resolved/missing_cik/unmapped_cik counts via EnrichmentStats*

| Automated alerting | Requires notification infrastructure (future milestone) |
